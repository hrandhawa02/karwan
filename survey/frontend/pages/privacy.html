Privacy

Karwan records a visit to a trailhead. It does not record a person.

The page does not ask for a name, an email, or a phone number. A visit is not tied to an account. Karwan does not sell notes, and it does not use them for advertising.

A visit is kept for as long as Karwan keeps visits. There is no set date when a note is deleted.

The map is OpenStreetMap. A name you type for a lot or a trail stays in Karwan. It is not sent to OpenStreetMap.

The database does not store your IP address. The host that serves the page may see a connection address in a short log. That log is not part of the visit.
